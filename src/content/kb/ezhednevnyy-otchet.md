## 📒 1. Тетрадь учёта (финансовый дневник)

Записываем строчку на сегодняшнюю дату в следующем порядке:

**Дата | Касса на начало смены | Оплата картой за день | Оплата наличными за день**

- **Переводы:** если были оплаты переводом (кроме аренды и индивидуальных), добавьте: + [сумма перевода].
- **Выдача зарплаты:** если выдали зарплату наличными, укажите: − [сумма] ([имя сотрудника]).
- Правила по остатку в кассе — у руководителя.

## 📊 2. Отчёт в Excel (статистика за день)

| Показатель | Что нужно вписать |
|---|---|
| Количество записей на день | Сколько новеньких было записано в программе (всех, даже если не пришли). |
| Количество пришедших | Сколько новеньких реально пришло на занятия (включая тех, кто записался, и тех, кто пришёл без записи). |
| Конверсия в приход | НЕ ЗАПОЛНЯЕМ |
| Кол-во новых покупок после занятия | Сколько новичков из пришедших купили свой ПЕРВЫЙ абонемент (0, 1, 2…). |
| Общая выручка (новые) | Общая сумма, на которую эти новички купили абонементы. |
| Конверсия в покупку | НЕ ЗАПОЛНЯЕМ |
| Количество индивидов | Сколько индивидуальных занятий прошло за день (0, 1, 2…). |
| Общая выручка с индивидов | Сумма, которую тренеры оплатили за аренду залов под индивидуальные (0, 250, 500…). |
| Количество часов аренды залов | Суммарное количество часов аренды (1; 1,5; 2; 3…). |
| Общая выручка с аренды | Сумма, которую заплатили за всю аренду. |
| Общая выручка за день с продаж | ВСЕ деньги с продаж: абонементы, разовые и пробные. **Без аренды и доп. товаров!** |
| Количество чеков | Общее количество совершённых продаж. |
| Средний чек | НЕ ЗАПОЛНЯЕМ |
| Количество чеков (доп. продукты) | Сколько штук доп. товаров продали (1 вода + 1 носки = 2 чека). |
| Общая выручка с доп. продуктов | Сумма, полученная за все доп. товары. |

> ‼️ **Важно:** обязательно сверьте итоговую выручку в отчёте с общей суммой всех продаж в программе. Они должны совпадать! Для этого выберите дату и инициатора — администраторов своего филиала (список — у руководителя).

## ✨ Дополнительные продукты: что продаём

Резинки, носки, вода, бутылки, спикеры, бомбочки для ванны.

- **Правило:** каждую позицию обязательно вносить в программу.
- **Учёт:** продажи доп. продуктов влияют на общее количество чеков и выручку.
