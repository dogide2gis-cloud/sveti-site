Каждому клиенту в Fitbase должен быть указан рекламный источник — так руководитель видит, какая реклама приводит людей. **Карточку без источника не оставляем.**

## Когда спрашиваем

- **Новые клиенты:** при первом контакте — звонок, сообщение, заявка или визит без записи. На первом визите проверяем, что источник стоит.
- **Действующие клиенты без источника:** спрашиваем на ресепшене при визите, в течение 2 недель. Без обзвона. По понедельникам — отчёт руководителю.

**Как спросить:** «Подскажите, как вы впервые узнали о нашей студии? Из ВКонтакте, по картам, по рекомендации?»

## Как отметить

Клиенты → карточка клиента → «Общее» → «Изменить» → «Рекламный источник» → «Сохранить изменения».

> Массово источник в Fitbase не проставляется — только вручную в каждой карточке.

## Какие источники выбирать

| Источник | Когда |
|---|---|
| Рекомендация клиента клуба | Посоветовал знакомый — укажите, кто именно |
| Вконтакте | Группа или реклама ВК |
| Instagram | Instagram |
| Telegram | Telegram |
| 2ГИС | Нашли в 2ГИС |
| Яндекс Карты | Нашли на Яндекс Картах |
| Яндекс поиск | Нашли через поиск Яндекса |
| TikTok | TikTok |
| Не помнит | Клиент не может вспомнить |
| Уточнить у клиента | Временная отметка (ставится автоматически на автозаявки) — заменить при первом контакте |

## Где смотреть результат

Отчёты и аналитика → Маркетинг → Сводный отчёт по рекламным источникам.
