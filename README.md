# Сайт студии танца «Свети»

Демо: https://dogide2gis-cloud.github.io/sveti-site/
Админ-панель: https://dogide2gis-cloud.github.io/sveti-site/admin/

## Как править сайт
1. Откройте админ-панель и войдите через токен GitHub (инструкция — в чате с Claude).
2. Выберите раздел: Курсы, Направления, Педагоги или «Страницы и настройки».
3. Внесите изменения и нажмите «Сохранить». Через 1–2 минуты сайт обновится сам.

## Устройство
- Astro (статический сайт), админка — Sveltia CMS (`public/admin/`).
- Контент: `src/content/` (курсы, направления, педагоги), `src/data/` (главная, цены, филиалы, вопросы, контакты).
- Картинки из админки: `public/uploads/`.
- Публикация демо: `.github/workflows/deploy-demo.yml`.
- Расписание и запись — виджет Fitbase на странице `/raspisanie/`.

## Для разработчика
```
npm install
npm run dev
```
